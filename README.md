## Research focus

- Item response theory and computerized adaptive testing

## Dissertation

**Bias-Aware Network Psychometrics**, Baylor University, 2026.

Methods for estimating psychological networks when measurement bias is present rather than assumed away, with simulation evidence on how invariance violations affect recovered network structure.
